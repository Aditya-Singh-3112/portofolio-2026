# Dark grayscale theme verification

The site-wide palette is now grayscale: charcoal and graphite surfaces, smoke and silver UI layers, and bone text. Teal and coral accents were removed from shared navigation, buttons, side rail, cards, tables, research panels, and CAAO diagram styling. The Galaxy background uses zero saturation for monochrome stars. Desktop and mobile Home, Research, and Projects screenshots passed, and typecheck/production build passed.
